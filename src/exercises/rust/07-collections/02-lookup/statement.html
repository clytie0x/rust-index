อ่านจำนวนนักเรียน n แล้วตามด้วย n บรรทัด แต่ละบรรทัดมีชื่อกับคะแนน จากนั้นมีชื่อที่ต้องการค้น อีกหนึ่งบรรทัด พิมพ์คะแนนของชื่อนั้น ถ้าไม่มีชื่อนี้ให้พิมพ์ missing ชื่อไม่ซ้ำ

ข้อมูลเข้า

บรรทัดแรกคือ n (1 ≤ n ≤ 100) ตามด้วย n บรรทัดของชื่อและคะแนน แล้วบรรทัดสุดท้ายคือชื่อที่ค้น

ข้อมูลออก

คะแนนหนึ่งจำนวน หรือคำว่า missing
