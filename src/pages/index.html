เรียนภาษา Rust ตั้งแต่ศูนย์

เอกสารชุดนี้ใช้ติว น้องเริ่มจากยังไม่เคยเขียน Rust ไปจนจัดโค้ดเป็นโมดูล ทดสอบ และอ่าน error ของตัวเองได้

เริ่มบทที่ 0 ดูเส้นทางเรียน

เส้นทางเรียน

ไล่ทีละบทจาก 0 ถึง 15 ชุดแรกปูเครื่องมือกับ ownership จากนั้นเป็นข้อมูลและ error แล้วจึงจัดโปรแกรมให้โตได้ และปิดด้วยของที่ใช้จริงอย่างเทสกับ cargo

ก่อนเริ่ม

  • ใช้ได้ทั้ง Windows, macOS และ Linux
  • ไม่ต้องมีพื้นฐาน Rust มาก่อน ถ้าเคยเขียนภาษาอื่นจะอ่านเร็วขึ้น แต่ไม่จำเป็น
  • เริ่มที่ บทที่ 0 แล้วไล่ไปทีละหน้า อย่าข้าม

วิธีอ่านให้ได้ผล

พิมพ์โค้ดทุกตัวอย่างเองแล้วรันด้วย cargo run อย่าก๊อปวาง การพิมพ์เองทำให้เจอ error จริง และการแก้ error คือการเรียนที่ได้ผลที่สุด
