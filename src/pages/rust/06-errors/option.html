6.1 Option

ค้นชื่อในห้องแล้วอาจไม่เจอ ถ้าคืน 0 จะปนกับคนที่สอบได้ศูนย์ Option คือ enum ที่มีสองทาง Some ถือค่าไว้ และ None แปลว่าไม่มี

match ให้ครบสองทาง

fn find_score(name: &str) -> Option<i32> {
    if name == "Ann" {
        Some(85)
    } else {
        None
    }
}

fn show(name: &str) {
    match find_score(name) {
        Some(n) => println!("{n}"),
        None => println!("missing"),
    }
}

fn main() {
    show("Ann");
    show("Bo");
}
  1. คืน Option<i32> คืออาจมี i32 หรือไม่มี
  2. Some(85) ห่อ 85 ไว้ None ไม่มีตัวเลข
  3. match ต้องรับทั้งสองทาง ชื่อ n ในแขน Some คือค่าที่ห่อมา
85
missing

ถามช่องของ Vec

หน้า 4.2 ใช้นิ้วชี้ดัชนีตรงๆ ซึ่งพังตอนรันถ้าช่องไม่มี get คืน Option จึงถามได้ก่อนใช้

fn main() {
    let scores = vec![70, 80];
    match scores.get(1) {
        Some(n) => println!("{n}"),
        None => println!("missing"),
    }
    match scores.get(4) {
        Some(n) => println!("{n}"),
        None => println!("missing"),
    }
}
80
missing

get คืน Option<&i32> พิมพ์ได้เลยเพราะตัวจัดรูปแบบตามเข้าไปดูค่าข้างใน

unwrap คือการสลัด Option ทิ้ง

แบบฝึกหัดบทก่อนหน้าใช้ unwrap ตอนอ่านข้อมูลเข้า เพื่อให้โปรแกรมสั้น ถ้าค่าเป็น None หรือ Err โปรแกรมจะหยุด unwrap ใช้ได้ตอนติวที่ตั้งใจให้ข้อมูลถูกเสมอ งานที่ข้อมูลอาจพังให้ match

สรุป

  • Option คือ Some หรือ None
  • match บังคับให้คิดถึงกรณีไม่มีค่า
  • Vec::get คืน Option แทนการชี้ดัชนีตรงๆ
