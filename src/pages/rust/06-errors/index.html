บทที่ 6 จัดการ error

ของบางอย่างอาจไม่มี และข้อความที่อ่านมาอาจไม่ใช่ตัวเลข บทนี้ให้ค่าที่อาจขาดเป็น Option และงานที่อาจพลาดเป็น Result

ในบทนี้

หน้าได้อะไร
6.1 Optionแทนค่าที่อาจไม่มี โดยไม่ใช้เลขมหัศจรรย์
6.2 Resultแยกงานสำเร็จกับงานพลาด โดยค่ากับเหตุผลอยู่คนละทาง
6.3 เครื่องหมายคำถามส่ง error กลับไปทันทีเมื่อขั้นใดขั้นหนึ่งพลาด
