6.3 เครื่องหมายคำถาม

ฟังก์ชันที่ทำหลายขั้น ถ้าทุกขั้นเขียน match จะยาว ? แปลว่า ถ้าค่านี้เป็น Err ให้คืน error ออกจากฟังก์ชันทันที ถ้าเป็น Ok ให้เอาค่าข้างในไปใช้ต่อ

ใช้ในฟังก์ชันที่คืน Result

fn double_score(text: &str) -> Result<i32, std::num::ParseIntError> {
    let n: i32 = text.trim().parse()?;
    Ok(n * 2)
}

fn main() {
    match double_score("40") {
        Ok(n) => println!("{n}"),
        Err(_) => println!("bad"),
    }
    match double_score("nope") {
        Ok(n) => println!("{n}"),
        Err(_) => println!("bad"),
    }
}
80
bad

บรรทัด parse? ถ้าแปลงไม่ได้ ฟังก์ชัน double_score คืน Err ทันที ไม่ไปคูณสอง ถ้าแปลงได้ n เป็น i32 แล้วบรรทัดถัดไปห่อด้วย Ok

ลองทำให้พัง

? ใช้ได้ในฟังก์ชันที่คืน Result หรือ Option เท่านั้น main ปกติคืน () จึงรับ ? ไม่ได้

fn parse_score(text: &str) -> Result<i32, std::num::ParseIntError> {
    text.parse()
}

fn main() {
    let n = parse_score("85")?;
    println!("{n}");
}

ตัดส่วน help ที่พูดถึง FromResidual และ Box ออก เพราะสองคำนั้นอยู่บทที่ 10 และบทที่ 13 ทางที่ใช้ตอนนี้คืออย่าใส่ ? ใน main ให้ match ที่ main แล้วใส่ ? ในฟังก์ชันที่คืน Result

สรุป

  • ? คืน error ทันทีเมื่อขั้นนั้นพลาด
  • ฟังก์ชันที่ใช้ ? ต้องคืน Result หรือ Option
  • ที่ main ให้ match แทน
