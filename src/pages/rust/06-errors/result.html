6.2 Result

ข้อความที่ผู้ใช้พิมพ์อาจไม่ใช่ตัวเลข Result คือ enum สองทางเหมือน Option แต่ทางที่พลาดถือเหตุผลไว้ Ok คือสำเร็จ Err คือพลาด

parse คืน Result

parse แปลงข้อความเป็นตัวเลข ถ้าแปลงไม่ได้จะได้ Err ที่บรรจุชนิด error ของการแปลง จำนวนเต็ม เราไม่ต้องอ่านข้างใน error ก็ได้ แค่แยกทาง

fn parse_score(text: &str) -> Result<i32, std::num::ParseIntError> {
    text.trim().parse()
}

fn show(text: &str) {
    match parse_score(text) {
        Ok(n) => println!("{n}"),
        Err(_) => println!("bad"),
    }
}

fn main() {
    show("85");
    show("nope");
}
85
bad
  • trim ตัดช่องว่างหัวท้ายก่อนแปลง
  • Err(_) รับ error ไว้แต่ไม่ใช้ชื่อ เพราะหน้านี้สนใจแค่ว่าพลาด
  • ชนิดหลังจุลภาคของ Result คือชนิดของความพลาด ตรงนี้คือ error จากการแปลงจำนวนเต็ม

สรุป

  • Result มี Ok กับ Err
  • parse คืน Result ไม่คืนตัวเลขตรงๆ
  • แยกทางด้วย match แทนการ unwrap เมื่อข้อมูลอาจเสีย
