5.2 เมธอดใน impl

ฟังก์ชัน passed ที่รับนักเรียนทั้งก้อนใช้ได้ แต่เรียกแบบ s.passed() อ่านง่ายกว่าว่านี่คือคำถามของนักเรียนคนนี้ เมธอดเขียนในบล็อก impl

self คือตัวที่ยืมมา

&self คือการยืม struct มาอ่าน แบบเดียวกับ &Student ในบทที่ 2 แค่เขียนสั้นเพราะอยู่ใน impl ของชนิดนั้น

struct Student {
    name: String,
    score: i32,
}

impl Student {
    fn passed(&self) -> bool {
        self.score >= 70
    }

    fn add_bonus(&mut self) {
        self.score += 5;
    }
}

fn main() {
    let mut s = Student {
        name: String::from("Ann"),
        score: 68,
    };
    s.add_bonus();
    println!("{}", s.score);
    println!("{}", s.passed());
    println!("{}", s.name);
}

  • &self อ่านได้อย่างเดียว &mut self แก้ฟิลด์ได้ และตัวแปรนอกต้องเป็น mut
  • เรียกเมธอดด้วยจุด ไม่ต้องส่ง self เอง
  • หลังเรียกทั้งสองเมธอด ฟิลด์ name ยังอยู่ เพราะไม่ได้ย้าย struct ออกไป

ฟังก์ชันที่ไม่มี self

ใน impl เขียน fn new โดยไม่มี self ได้ เรียกด้วย Student::new() ใช้ตอนอยากมีทางสร้างค่าที่ตรวจฟิลด์ให้ ชุดนี้ยังใช้การสร้างตรงๆ พอ

สรุป

  • เมธอดอยู่ใต้ impl ชื่อชนิด
  • &self ยืมมาอ่าน &mut self ยืมมาแก้
  • เรียกด้วยจุดบนค่าที่มีอยู่
