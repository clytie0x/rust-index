5.1 struct

ตัวแปร name กับ score คนละตัวหลุดกันง่ายเมื่อมีนักเรียนหลายคน struct คือชนิดที่เรานิยามเอง เพื่อให้ฟิลด์ที่เดินด้วยกันอยู่ก้อนเดียว

ฟิลด์มีชื่อ

struct Student {
    name: String,
    score: i32,
}

fn main() {
    let s = Student {
        name: String::from("Ann"),
        score: 85,
    };
    println!("{}", s.name);
    println!("{}", s.score);
}
  1. struct ตั้งชื่อชนิด ฟิลด์แต่ละตัวมีชนิดของตัวเอง
  2. สร้างค่าด้วยชื่อฟิลด์ครบทุกตัว ลำดับในวงเล็บปีกกาไม่สำคัญเท่าชื่อ
  3. อ่านฟิลด์ด้วยจุด s.name ค่า name เป็น String ที่ struct เป็นเจ้าของ
Ann
85

ฟิลด์ที่เป็น String ถูกย้ายเข้า struct ตอนสร้าง ตัวแปรเดิมที่ใช้สร้างจึงใช้ต่อไม่ได้ ถ้ายังต้องใช้ชื่อเดิมให้ clone ซึ่งบทที่ 7 จะเจออีกทีตอนกุญแจของแมป

ลองทำให้พัง

ลืมฟิลด์ score rustc ไม่เดาให้ เพราะ struct ต้องครบทุกฟิลด์ตั้งแต่สร้าง

struct Student {
    name: String,
    score: i32,
}

fn main() {
    let s = Student {
        name: String::from("Ann"),
    };
    println!("{}", s.score);
}
error[E0063]: missing field `score` in initializer of `Student`
 --> main.rs:7:13
  |
7 |     let s = Student {
  |             ^^^^^^^ missing `score`

ข้อความนี้ตัดบรรทัด aborting due to กับลิงก์อธิบายรหัส error ออก เนื้อที่เหลือคือ rustc ชี้ว่าตัวสร้างยังขาด score

สรุป

  • struct รวมฟิลด์ที่มีชื่อและชนิด
  • สร้างค่าต้องใส่ครบทุกฟิลด์
  • อ่านฟิลด์ด้วยจุด
