5.3 enum

เกรดไม่ควรเป็น String ว่างที่พิมพ์ผิดได้ enum คือชนิดที่มีตัวเลือกชุดหนึ่ง rustc รู้ว่ามีกี่ทาง และ match จากหน้า 3.3 บังคับให้คิดถึงครบ

แต่ละทางคือ variant

enum Grade {
    A,
    B,
    C,
}

fn label(score: i32) -> Grade {
    if score >= 80 {
        Grade::A
    } else if score >= 70 {
        Grade::B
    } else {
        Grade::C
    }
}

fn show(grade: Grade) {
    match grade {
        Grade::A => println!("A"),
        Grade::B => println!("B"),
        Grade::C => println!("C"),
    }
}

fn main() {
    show(label(85));
    show(label(70));
    show(label(61));
}
A
B
C

เขียน Grade::A เพราะ A อยู่ในชนิด Grade แขนของ match ต้องมีครบสามทาง จะใช้ _ รับที่เหลือก็ได้ แต่เกรดมีไม่กี่ตัว เขียนครบอ่านชัดกว่า

variant ถือค่าได้

บางทางมีข้อมูลติดมาด้วย เช่น รู้คะแนน หรือยังไม่รู้ ตัวเลือกที่ไม่มีค่ากับตัวเลือกที่มี i32 อยู่ชนิดเดียวกันได้

enum Answer {
    Known(i32),
    Missing,
}

fn show(answer: Answer) {
    match answer {
        Answer::Known(n) => println!("{n}"),
        Answer::Missing => println!("missing"),
    }
}

fn main() {
    show(Answer::Known(85));
    show(Answer::Missing);
}
85
missing

Option ในบทที่ 6 เป็น enum ของไลบรารีมาตรฐาน ที่มี Some ถือค่า และ None ที่ไม่มีค่า แนวคิดเดียวกับ Answer นี้

สรุป

  • enum คือชุดตัวเลือกที่ rustc รู้จักครบ
  • เรียกตัวเลือกด้วย ชื่อ::ตัวเลือก
  • match ต้องครอบทุกตัวเลือก หรือมี _
