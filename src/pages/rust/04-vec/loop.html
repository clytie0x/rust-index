4.3 วนลิสต์

โจทย์รวมคะแนนไม่อยากเขียนดัชนีทีละช่อง for ที่เคยเดินช่วงตัวเลขในหน้า 3.2 เดินสมาชิกของลิสต์ได้เหมือนกัน

ยืมทั้งลิสต์ตอนวน

ถ้าเขียน for score in scores โดย scores เป็น Vec ลิสต์ถูกย้ายเข้าลูป พอจบลูปใช้ชื่อเดิมไม่ได้ งานติวมักต้องพิมพ์ทั้งผลรวมและความยาว จึงยืมด้วย &scores

fn main() {
    let scores = vec![70, 80, 90];
    let mut total = 0;
    for score in &scores {
        total += score;
    }
    println!("{total}");
    println!("{}", scores.len());
}
240
3
  • score ในลูปคือ &i32 บวกเข้า total ได้โดยไม่ต้องเขียน * เอง
  • หลังลูป scores.len() ยังเรียกได้ เพราะยืมอย่างเดียว
  • i32 เป็น Copy จากบทที่ 2 แต่ Vec ไม่ใช่ การยืมจึงสำคัญตรงลิสต์ ไม่ใช่ตรงตัวเลข

เมื่อต้องรู้ดัชนี

บางโจทย์ต้องพิมพ์ว่าคนที่เท่าไหร่ได้คะแนนเท่าไหร่ ใช้ iter().enumerate() ได้คู่ของดัชนีกับค่า รายละเอียดของ iterator อยู่ในบทที่ 12 ตอนนี้จำแค่ว่าได้เลขลำดับเริ่มที่ 0

fn main() {
    let scores = vec![70, 80];
    for (i, score) in scores.iter().enumerate() {
        println!("{i} {score}");
    }
}
0 70
1 80

สรุป

  • for score in &scores อ่านทุกช่องโดยลิสต์ยังอยู่
  • บวกสะสมได้ในตัวแปร mut นอกลูป
  • อยากได้เลขลำดับใช้ iter().enumerate()
