4.2 Vec

รายชื่อห้องหรือคะแนนที่อ่านจากไฟล์มักยาวขึ้นระหว่างรัน Vec คือลิสต์ที่โปรแกรมเป็นเจ้าของ และต่อท้ายได้

สร้างแล้วต่อท้าย

มาโคร vec! สร้าง Vec คล้าย println! ที่เป็นมาโคร ไม่ใช่ฟังก์ชัน ถ้าจะ push ต้องเป็น let mut เพราะค่าในลิสต์ถูกแก้

fn main() {
    let mut scores = vec![70, 80];
    scores.push(90);
    println!("{}", scores.len());
    println!("{}", scores[0]);
    println!("{}", scores[2]);
}
  1. vec![70, 80] ได้ Vec ของ i32 สองช่อง
  2. push วาง 90 ต่อท้าย จึงต้องยืมแบบแก้ได้ ตัวแปรเลยเป็น mut
  3. หลัง push มีสามช่อง ดัชนี 2 คือค่าที่เพิ่งใส่
3
70
90

Vec::new() สร้างลิสต์ว่าง แล้ว push ทีหลังก็ได้ ตอน push ตัวแรก rustc เดาชนิดจากค่านั้น

ลองทำให้พัง

เอา mut ออกแล้ว push rustc ไม่ให้ผ่าน เพราะลิสต์ที่แก้ค่าไม่ได้ถูกขอยืมมาแก้

fn main() {
    let scores = vec![70, 80];
    scores.push(90);
}
error[E0596]: cannot borrow `scores` as mutable, as it is not declared as mutable
 --> main.rs:3:5
  |
3 |     scores.push(90);
  |     ^^^^^^ cannot borrow as mutable
  |
help: consider changing this to be mutable
  |
2 |     let mut scores = vec![70, 80];
  |         +++

ทางแก้ตรงกับที่ rustc เสนอ คือใส่ mut ถ้าลิสต์นี้อ่านอย่างเดียวจริงๆ ก็ไม่ต้อง push

ดัชนีเกินปลายเป็นเรื่องตอนรัน

ถ้าเขียน scores[9] ทั้งที่ไม่มีช่องนั้น โปรแกรมคอมไพล์ผ่านแล้วหยุดตอนรัน หน้า 6.1 จะใช้ get ที่คืน Option เมื่ออยากถามก่อนว่าช่องมีไหม

สรุป

  • vec! สร้าง Vec
  • push ต่อท้าย และตัวแปรต้องเป็น mut
  • อ่านด้วยดัชนีได้เมื่อรู้ว่าช่องนั้นมีจริง
