4.1 อาเรย์กับสไลซ์

บางครั้งจำนวนช่องรู้ตั้งแต่เขียนโค้ด เช่น คะแนนสามวิชาของคนเดียว ไม่ต้องโตตอนรัน อาเรย์คือก้อนนั้น ความยาวเป็นส่วนหนึ่งของชนิด

ความยาวอยู่ในชนิด

[i32; 3] คืออาเรย์ของ i32 สามช่อง ช่องแรกอยู่ที่ดัชนี 0 ถ้าอ่านช่องที่ไม่มี โปรแกรมหยุดตอนรัน ไม่ใช่ตอนคอมไพล์ จึงอ่านเฉพาะช่องที่รู้ว่ามี

fn main() {
    let scores = [70, 80, 90];
    println!("{}", scores.len());
    println!("{}", scores[0]);
    println!("{}", scores[2]);
}
  1. [70, 80, 90] สร้างอาเรย์สามช่อง rustc เดาชนิดเป็น [i32; 3]
  2. len คือจำนวนช่อง ซึ่งอาเรย์ตัวนี้คือ 3 เสมอ
  3. ดัชนี 2 คือช่องสุดท้าย เพราะนับเริ่มที่ 0

70
90

สไลซ์คือหน้าต่างที่มองบางช่วง

ฟังก์ชันมักไม่อยากผูกกับความยาวตายตัว สไลซ์เขียนว่า &[i32] คือยืมช่วงของอาเรย์มาอ่าน ความยาวจึงไม่อยู่ในชนิด อยู่ในค่าตอนรัน

fn show(top: &[i32]) {
    println!("{}", top.len());
    println!("{}", top[0]);
}

fn main() {
    let scores = [70, 80, 90];
    show(&scores[0..2]);
}
2
70
  • 0..2 คือช่อง 0 กับ 1 ไม่รวม 2 แบบเดียวกับช่วงในหน้า 3.2
  • &scores[0..2] ยืมช่วงนั้น ส่งเข้าฟังก์ชันที่รับ &[i32] ได้
  • อาเรย์ทั้งก้อนส่งเป็นสไลซ์ได้ด้วย &scores เพราะ Rust ยืมทั้งก้อนให้

อาเรย์เมื่อไหร่ Vec เมื่อไหร่

ถ้ารู้จำนวนช่องตั้งแต่เขียนโค้ดและไม่ต่อท้าย ใช้อาเรย์ ถ้าต้อง push หรือยังไม่รู้ว่าจะมีกี่คน ใช้ Vec ในหน้าถัดไป

สรุป

  • อาเรย์เขียน [ค่า, ค่า] ความยาวเป็นส่วนของชนิด
  • ดัชนีเริ่มที่ 0 และต้องชี้ช่องที่มีจริง
  • สไลซ์ &[i32] คือการยืมช่วงหนึ่งของลิสต์
