9.2 สิทธิ์ pub

ไม่ใช่ทุกฟังก์ชันควรโผล่ให้คนนอกเรียก ตัวช่วยที่เปลี่ยนบ่อยควรอยู่ข้างใน แล้วให้ฟังก์ชัน pub ตัวเดียวเป็นประตู

ข้างในเรียกของส่วนตัวได้

mod grade {
    fn band(score: i32) -> &'static str {
        if score >= 80 {
            "A"
        } else {
            "C"
        }
    }

    pub fn show(score: i32) {
        println!("{}", band(score));
    }
}

fn main() {
    grade::show(85);
    grade::show(60);
}
A
C

band ไม่มี pub แต่ show ที่อยู่ในโมดูลเดียวกันเรียกได้ main เรียกได้แค่ show

ลองทำให้พัง

mod grade {
    fn band(score: i32) -> &'static str {
        if score >= 80 { "A" } else { "C" }
    }
}

fn main() {
    println!("{}", grade::band(85));
}

  |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

เติม pub หน้า fn band ถ้าตั้งใจให้คนนอกเรียก หรือเรียกผ่านฟังก์ชันประตูอย่าง show

สรุป

  • ของในโมดูลเป็นส่วนตัวจนกว่าจะใส่ pub
  • ฟังก์ชันในโมดูลเดียวกันเรียกของส่วนตัวได้
  • คนนอกเรียกของส่วนตัวไม่ได้ rustc บอกว่า private
