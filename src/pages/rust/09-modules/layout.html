9.3 use กับโครง cargo

เขียน grade::band ซ้ำๆ อ่านยาว use ดึงชื่อเข้า scope ปัจจุบัน แล้วเรียกสั้นได้

ดึงชื่อมาใกล้ๆ

mod grade {
    pub fn band(score: i32) -> &'static str {
        if score >= 80 {
            "A"
        } else {
            "C"
        }
    }
}

use grade::band;

fn main() {
    println!("{}", band(85));
    println!("{}", band(50));
}
A
C

use ไม่ได้คัดลอกโค้ด แค่ทำให้ชื่อ band ชี้ไปที่ฟังก์ชันในโมดูล

แยกไฟล์เมื่อโปรเจกต์โต

ของจริงไม่ยัดทุกโมดูลไว้ใน main.rs cargo มองหาไฟล์ให้เอง ถ้าระบุ mod grade; โดยไม่มีบล็อกปีกกา มันจะอ่าน src/grade.rs โปรเจกต์ที่มีทั้งโปรแกรมและไลบรารีใช้ src/lib.rs เป็นรากของ crate ที่คนอื่นเรียก และ src/main.rs เป็นโปรแกรม

src/main.rs
src/grade.rs
src/lib.rs

ตัวตรวจของเว็บคอมไพล์ทีละไฟล์

ตัวอย่างในหน้ามี mod พร้อมบล็อกปีกกา จึงอยู่ไฟล์เดียว เวลาทำโปรเจกต์ของตัวเองให้แยกไฟล์ตามที่ cargo มองหา แล้วรันด้วย cargo run เหมือนบทที่ 0

สรุป

  • use ทาง::ชื่อ ให้เรียกชื่อสั้นได้
  • mod ชื่อ; ไม่มีบล็อก แปลว่าโค้ดอยู่ในไฟล์ src/ชื่อ.rs
  • src/main.rs คือโปรแกรม src/lib.rs คือ crate ที่เปิดให้เรียก
