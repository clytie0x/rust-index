9.1 mod ในไฟล์เดียว

crate คือหน่วยที่ cargo คอมไพล์หนึ่งครั้ง โปรเจกต์จาก cargo new มี crate ของโปรแกรม เป็นไฟล์ src/main.rs โมดูลคือกล่องชื่อข้างใน crate นั้น เริ่มเขียนในไฟล์เดียวก่อนได้ ตัวตรวจของเว็บนี้ก็คอมไพล์ทีละไฟล์แบบนี้

กล่องชื่อ

ฟังก์ชันข้างในโมดูลคนนอกมองไม่เห็น ถ้า main ต้องเรียก ให้เปิดด้วย pub หน้า 9.2 จะดูว่าเกิดอะไรเมื่อลืมเปิด

mod grade {
    pub fn band(score: i32) -> &'static str {
        if score >= 80 {
            "A"
        } else if score >= 70 {
            "B"
        } else {
            "C"
        }
    }
}

fn main() {
    println!("{}", grade::band(85));
    println!("{}", grade::band(70));
    println!("{}", grade::band(61));
}
  1. mod grade สร้างกล่องชื่อ grade
  2. pub เปิดให้โค้ดนอกโมดูลเรียกฟังก์ชันนี้ได้
  3. grade::band คือชื่อทางเดิน จากโมดูลไปฟังก์ชัน
A
B
C

สรุป

  • crate ของโปรแกรมเริ่มที่ src/main.rs
  • mod คือกล่องใส่ชื่อ
  • เรียกของข้างในด้วย :: และของที่คนนอกใช้ต้อง pub
