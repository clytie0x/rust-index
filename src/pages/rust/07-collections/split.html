7.1 แตกข้อความ

แบบฝึกหัดตั้งแต่บทที่ 1 อ่านบรรทัดแล้วตัดคำอยู่แล้ว หน้านี้ทำให้เห็นเครื่องมือนั้นตรงๆ split_whitespace แตกตรงช่องว่างทุกชนิด และยุบช่องว่างที่ติดกันเหลือจุดตัดเดียว

นับคำ

fn main() {
    let line = "Ann 85 Mali 90";
    let mut count = 0;
    for word in line.split_whitespace() {
        count += 1;
        println!("{word}");
    }
    println!("count = {count}");
}
Ann
85
Mali
90
count = 4

แต่ละ word เป็น &str ยืมจาก line ไม่ได้สร้าง String ใหม่ทุกคำ ถ้าต้องเก็บคำไว้หลัง line ตาย ให้ to_string ซึ่งหน้า HashMap ใช้แบบนั้นกับชื่อ

สรุป

  • split_whitespace ให้ทีละคำแบบ &str
  • ช่องว่างติดกันนับเป็นตัวตัดอันเดียว
  • อยากเป็นเจ้าของคำนั้นใช้ to_string
