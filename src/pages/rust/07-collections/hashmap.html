7.2 HashMap

ถ้ามีนักเรียนหลายคนแล้วต้องหาคะแนนจากชื่อ การเดิน Vec ทุกครั้งยังทำได้ แต่เมื่อชื่อคือกุญแจ HashMap เก็บคู่กุญแจกับค่าไว้ให้ค้นทีหลัง

ใส่แล้วค้น

แมปอยู่ใน std::collections ต้อง use ก่อน get คืน Option แบบเดียวกับช่องของ Vec ในหน้า 6.1

use std::collections::HashMap;

fn main() {
    let mut scores = HashMap::new();
    scores.insert(String::from("Ann"), 85);
    scores.insert(String::from("Mali"), 72);
    match scores.get("Ann") {
        Some(n) => println!("{n}"),
        None => println!("missing"),
    }
    match scores.get("Bo") {
        Some(n) => println!("{n}"),
        None => println!("missing"),
    }
}
  1. HashMap::new สร้างแมปว่าง ต้อง mut เพราะ insert แก้แมป
  2. กุญแจเป็น String ที่แมปเป็นเจ้าของ ค่าเป็น i32
  3. get รับ &str ได้แม้กุญแจที่เก็บไว้เป็น String
85
missing

ลองทำให้พัง

ใส่ String เป็นกุญแจคือการย้ายค่าเข้าแมป ชื่อเดิมใช้ต่อไม่ได้ นี่คือ move จากบทที่ 2 กับของที่ไม่ได้ Copy

use std::collections::HashMap;

fn main() {
    let mut scores = HashMap::new();
    let name = String::from("Ann");
    scores.insert(name, 80);
    println!("{name}");
}

สรุป

  • HashMap เก็บคู่กุญแจกับค่า
  • get คืน Option
  • กุญแจที่เป็น String ถูกย้ายเข้าแมป
