7.3 HashSet

บางงานไม่ต้องการคะแนน ต้องการแค่รู้ว่าชื่อนี้เคยเจอแล้วหรือยัง HashSet คือชุดของค่า ไม่มีคู่ค่าที่สอง ใส่ซ้ำแล้วความยาวไม่เพิ่ม

กันชื่อซ้ำ

use std::collections::HashSet;

fn main() {
    let mut names = HashSet::new();
    names.insert(String::from("Ann"));
    names.insert(String::from("Ann"));
    names.insert(String::from("Mali"));
    println!("{}", names.len());
    println!("{}", names.contains("Ann"));
    println!("{}", names.contains("Bo"));
}
2
true
false
  • ใส่ Ann สองครั้ง แต่ len เป็น 2 เพราะเหลือคนละชื่อ
  • contains ถามว่ามีค่านี้ไหม ได้ bool
  • ชุดนี้ก็ไม่รับประกันลำดับตอนวน อย่าพิมพ์รายชื่อทั้งชุดแล้วล็อกบรรทัด

สรุป

  • HashSet เก็บค่าไม่ซ้ำ
  • insert ค่าเดิมซ้ำไม่เพิ่มจำนวน
  • contains ตอบว่ามีหรือไม่มี
