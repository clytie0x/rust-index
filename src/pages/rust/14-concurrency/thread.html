14.1 เธรดกับ join

เธรดคืองานที่เดินคู่กับ main ถ้าพิมพ์จากหลายเธรดโดยไม่จัดลำดับ บรรทัดจะสลับกันทุกครั้งที่รัน ชุดนี้เลยให้เธรดคืนค่า แล้ว join รอให้จบก่อนค่อยพิมพ์จาก main

รอค่ากลับ

use std::thread;

fn main() {
    let handle = thread::spawn(|| 40 + 5);
    let score = handle.join().unwrap();
    println!("{score}");
}
45

spawn ได้มือจับ join รอจน closure จบ แล้วให้ค่าที่ closure คืน unwrap ตรงนี้แปลว่าเราไม่จัดการกรณีเธรด panic ในบทภาพรวมนี้

ลองทำให้พัง

closure ของเธรดอาจมีชีวิตยาวกว่าฟังก์ชันที่สร้างมัน การยืม name จาก main จึงไม่พอ ต้องย้ายเข้าไปด้วย move

use std::thread;

fn main() {
    let name = String::from("Ann");
    let handle = thread::spawn(|| {
        println!("{name}");
    });
    handle.join().unwrap();
}

เติม move ตาม help แล้ว name ถูกย้ายเข้าเธรด ใช้ใน main หลัง spawn ไม่ได้อีก ป้าย 'static ในข้อความคือระยะที่เธรดต้องการ ของที่ย้ายเข้าไปเป็นของเธรดเองจึงผ่าน

สรุป

  • thread::spawn เริ่มงานอีกเส้น
  • join รอก่อนใช้ค่าที่งานนั้นคืน
  • closure ของเธรดใช้ move เมื่อต้องถือค่าจากนอก
