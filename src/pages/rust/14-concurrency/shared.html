14.3 Arc กับ Mutex

บางตัวเลขต้องให้หลายเธรดบวกเข้าก้อนเดียว Mutex คือกุญแจ ครั้งหนึ่งมีคนแก้ได้คนเดียว Arc คือตัวนับเจ้าของแบบ Rc แต่ส่งข้ามเธรดได้

บวกทีละคน

use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let total = Arc::new(Mutex::new(0));
    let mut handles = Vec::new();
    for n in [10, 20, 30] {
        let total = Arc::clone(&total);
        handles.push(thread::spawn(move || {
            let mut slot = total.lock().unwrap();
            *slot += n;
        }));
    }
    for handle in handles {
        handle.join().unwrap();
    }
    println!("{}", *total.lock().unwrap());
}
60
  • แต่ละเธรดได้ Arc ของตัวเองที่ชี้ mutex เดียวกัน
  • lock รอจนกว่าจะได้กุญแจ แล้วบวก
  • พิมพ์หลัง join ครบ จึงได้ 60 เสมอ ไม่ขึ้นกับว่าเธรดไหนจบก่อน

อย่าล็อกค้างแล้วไปรอเธรดอื่น

ถ้าถือผลจาก lock ไว้แล้วไป join งานที่ต้องใช้กุญแจเดียวกัน อาจรอซึ่งกันและกันตลอด ปล่อยกุญแจให้จบใน closure แล้วค่อย join แบบตัวอย่างนี้

สรุป

  • Mutex ให้แก้ค่าทีละเธรด
  • Arc ส่งเจ้าของข้ามเธรดได้
  • รอทุกเธรดจบก่อนอ่านผลสุดท้าย
