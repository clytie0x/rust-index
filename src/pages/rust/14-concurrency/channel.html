14.2 ช่องส่งข้อความ

แทนที่จะให้สองเธรดแก้ก้อนเดียวกัน ส่งสำเนาของค่าผ่านช่อง ฝั่งส่งคือ tx ฝั่งรับคือ rx จาก mpsc::channel ชื่อย่อมาจากหลายคนส่ง คนเดียวรับ

ส่งคะแนนข้ามไป

use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();
    thread::spawn(move || {
        tx.send(85).unwrap();
    });
    let score = rx.recv().unwrap();
    println!("{score}");
}
85

move ย้าย tx เข้าเธรด send ส่ง 85 recv รอจนกว่าจะมีค่า แล้ว main พิมพ์ทีเดียว ผลจึงไม่สลับบรรทัด

สรุป

  • channel ส่งค่าข้ามเธรดโดยไม่แชร์ตัวแปร
  • send ยิงค่า recv รอรับ
  • ย้ายฝั่งส่งเข้าเธรดด้วย move
