3.2 if และ loop

หน้านี้เลือกทางด้วยเงื่อนไข แล้ววนทำซ้ำ สองอย่างนี้พอสำหรับโจทย์นับและตัดเกรดช่วงแรก

if เป็นนิพจน์

if ใน Rust ให้ค่ากลับได้ แขนที่เลือกต้องให้ค่าชนิดเดียวกัน เงื่อนไขต้องเป็น bool ไม่ใช่ตัวเลข

fn grade(score: i32) -> &'static str {
    if score >= 80 {
        "A"
    } else if score >= 70 {
        "B"
    } else {
        "C"
    }
}

fn main() {
    println!("{}", grade(85));
    println!("{}", grade(70));
    println!("{}", grade(61));
}

A
B
C

แต่ละแขนไม่มี ; เพราะข้อความเกรดคือค่าที่ if ส่งให้ฟังก์ชันคืนต่อ &'static str คือข้อความที่ยืมมาและมีชีวิตตลอดทั้งโปรแกรม ข้อความในเครื่องหมายคำพูดคู่เป็นแบบนี้

>= อ่านว่ามากกว่าหรือเท่ากับ เกรด A เริ่มที่ 80 และ B เริ่มที่ 70 คะแนนที่น้อยกว่า 70 ตกไปแขน else

อย่าใช้ = ในเงื่อนไข

fn main() {
    let score = 70;
    if score = 80 {
        println!("A");
    }
}

= คือการใส่ค่า ไม่ใช่การถามว่าเท่ากัน การถามใช้ == rustc เติม = ให้อีกตัวในบรรทัด help

while

while ทำซ้ำตราบเท่าที่เงื่อนไขยังเป็น true

fn main() {
    let mut n = 1;
    while n <= 3 {
        println!("{n}");
        n += 1;
    }
}

1
2
3

n += 1 คือบวกหนึ่งแล้วใส่กลับ ถ้าลืมบรรทัดนี้ n เป็น 1 ตลอด ลูปไม่จบ โปรแกรมแบบนั้นห้ามใส่ในตัวอย่างที่ให้ตัวตรวจรัน

for กับช่วงตัวเลข

ถ้ารู้อยู่แล้วว่าจะเดินจาก 1 ถึง 3 ให้ใช้ for ช่วง 1..=3 รวมปลายทั้งสองข้าง

fn main() {
    for i in 1..=3 {
        println!("i = {i}");
    }
}

i = 1
i = 2
i = 3

1..3 ไม่มี = จะได้แค่ 1 กับ 2 ไม่รวม 3 โจทย์ที่บอกตั้งแต่ 1 ถึง n ส่วนใหญ่ใช้ 1..=n

สรุป

  • if ต้องการ bool เทียบเท่าใช้ ==
  • แขนของ if ที่ใช้เป็นค่าคืน ห้ามใส่ ; ท้ายนิพจน์
  • while วนตามเงื่อนไข for i in 1..=n วนรวม n
