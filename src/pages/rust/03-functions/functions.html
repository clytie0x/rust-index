3.1 ฟังก์ชัน

ฟังก์ชันคือชุดคำสั่งที่ตั้งชื่อไว้ เรียกซ้ำได้ และส่งค่ากลับได้ main ที่เขียนมาตั้งแต่บทที่ 0 ก็เป็นฟังก์ชันตัวหนึ่ง

ฟังก์ชันที่ทำงานอย่างเดียว

fn line() {
    println!("----------");
}

fn main() {
    line();
    println!("Room 4");
    line();
}

----------
Room 4
----------

ไม่มีลูกศรหลังวงเล็บ แปลว่าไม่ได้คืนค่าอะไร เรียกด้วยชื่อแล้วตามด้วยวงเล็บ

ส่งค่ากลับ

ชนิดของค่าที่คืนเขียนหลัง -> บรรทัดสุดท้ายของฟังก์ชันถ้าไม่มี ; จะเป็นค่าที่ถูกคืน ไม่ต้องเขียน return ก็ได้

fn total(math: i32, science: i32) -> i32 { // (1)!
    math + science // (2)!
}

fn main() {
    let sum = total(78, 91); // (3)!
    println!("{sum}");
}
  1. รับ i32 สองตัว แล้วคืน i32 หนึ่งตัว
  2. ไม่มี ; ท้ายบรรทัดนี้ ผลบวกจึงถูกส่งกลับ เป็นนิพจน์ (expression) ไม่ใช่คำสั่งที่ทิ้งค่า
  3. เรียกฟังก์ชันแล้วเก็บค่าที่คืนได้เหมือนเก็บผลบวกทั่วไป

ใส่ ; ที่บรรทัดสุดท้าย

fn total(math: i32, science: i32) -> i32 {
    math + science;
}

fn main() {
    println!("{}", total(70, 80));
}

error[E0308]: mismatched types
 --> main.rs:1:38
  |
1 | fn total(math: i32, science: i32) -> i32 {
  |    -----                             ^^^ expected `i32`, found `()`
  |    |
  |    implicitly returns `()` as its body has no tail or `return` expression
2 |     math + science;
  |                   - help: remove this semicolon to return this value

() คือค่าว่าง ไม่มีข้อมูล พอใส่ ; บรรทัดนั้นกลายเป็นคำสั่งที่ทิ้งผลบวกไป ฟังก์ชันเลยไม่ได้คืน i32 ตามที่หัวฟังก์ชันสัญญาไว้ rustc ชี้ให้ลบ ; ตรงนั้น

; ท้ายบรรทัดสุดท้ายคือจุดที่พลาดบ่อย

บรรทัดที่อยากให้เป็นคำตอบของฟังก์ชัน ห้ามปิดด้วย ; บรรทัดที่เป็นคำสั่งอย่าง println! ยังต้องมี ; เหมือนเดิม

สรุป

  • ประกาศด้วย fn ชื่อ(พารามิเตอร์) -> ชนิดที่คืน
  • บรรทัดสุดท้ายที่ไม่มี ; คือค่าที่คืน
  • ฟังก์ชันที่ไม่คืนค่า ไม่ต้องเขียน ->
