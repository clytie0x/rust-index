3.3 match

match แยกทางตามค่า แต่บังคับให้คิดถึงทุกกรณีที่ชนิดนั้นเป็นไปได้ ใช้เมื่อ if เริ่มมีหลายช่วง และกลัวลืมช่วงใดช่วงหนึ่ง

fn label(score: i32) -> &'static str {
    match score {
        80..=100 => "A",
        70..=79 => "B",
        _ => "C",
    }
}

fn main() {
    println!("{}", label(85));
    println!("{}", label(70));
    println!("{}", label(40));
}

B
C
  • แต่ละแขนเขียน รูปแบบ => ค่า แล้วตามด้วยจุลภาค
  • 80..=100 คือช่วงที่รวม 80 และรวม 100
  • _ คือที่เหลือทั้งหมด ในตัวอย่างนี้คะแนนที่ต่ำกว่า 70 และคะแนนที่เกิน 100 ตกมาที่ C

แขนสุดท้ายของฟังก์ชันนี้ไม่มี ;

match ทั้งก้อนคือนิพจน์ที่ฟังก์ชันคืน หลังปีกกาปิดของ match จึงไม่มี ; เหมือนบรรทัด math + science ในหน้า 3.1

ลองทำให้ไม่ครบ

fn main() {
    let score = 80;
    match score {
        80 => println!("A"),
    }
}

i32 มีค่าได้อีกเยอะนอกจาก 80 rustc เลยไม่ให้ผ่านจนกว่าจะครอบคลุม มันยังเสนอแขนเติมให้ในข้อความ help ซึ่งตัดออกจากกล่องนี้ ทางที่อ่านง่ายที่สุดในช่วงเริ่มคือใส่แขน _

สรุป

  • match ต้องครบทุกค่า หรือมี _ รับส่วนที่เหลือ
  • ช่วงตัวเลขใช้ ..= เมื่ออยากรวมปลายทั้งสองข้าง
  • ใช้แทน if ที่แตกเป็นหลายช่วงได้ แต่ยังไม่จำเป็นทุกครั้ง
