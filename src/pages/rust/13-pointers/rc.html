13.2 Rc

เจ้าของคนเดียวจากบทที่ 2 ครอบคลุมงานส่วนมาก เมื่อสองส่วนของโปรแกรมต้องใช้ข้อความเดียวกันต่อ และไม่มีใครควรเป็นเจ้าของคนเดียว Rc นับว่ามีกี่คนถืออยู่ ตัวสุดท้ายที่ปล่อยคือคนเก็บก้อนทิ้ง

Rc ใช้ในเธรดเดียว งานข้ามเธรดอยู่ในบทที่ 14

เพิ่มเจ้าของด้วย clone

use std::rc::Rc;

fn main() {
    let name = Rc::new(String::from("Ann"));
    let also = Rc::clone(&name);
    println!("{name}");
    println!("{also}");
    println!("{}", Rc::strong_count(&name));
}
  1. Rc::new ห่อ String เริ่มมีเจ้าของหนึ่งคน
  2. Rc::clone ไม่ได้คัดลอกข้อความ แค่นับเจ้าของเพิ่ม ชื่อ also ชี้ก้อนเดิม
  3. strong_count คือ 2 เพราะมี name กับ also

ลองทำให้พัง

* จะดึง String ออกมาเป็นเจ้าของคนเดียวไม่ได้ เพราะยังมีตัวนับเจ้าของอยู่ ให้ใช้ก้อนผ่าน Rc หรือ clone ข้อความถ้าต้องการ String ของตัวเอง

use std::rc::Rc;

fn main() {
    let name = Rc::new(String::from("Ann"));
    let moved = *name;
    println!("{moved}");
}

สรุป

  • Rc ให้มีเจ้าของหลายคนในเธรดเดียว
  • Rc::clone เพิ่มตัวนับ ไม่ได้สำเนาข้างในเสมอไป
  • ดึงของข้างในออกด้วยการย้ายไม่ได้
