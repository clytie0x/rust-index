13.1 Box

Box ถือค่าบน heap แล้วเหลือตัวชี้ขนาดคงที่บนสแตก ใช้เมื่อชนิดต้องบรรจุตัวเอง เช่น ลิสต์ที่แต่ละข้อถือคะแนนและลิสต์ที่เหลือ ถ้าใส่ List ตรงๆ ใน List ขนาดไม่รู้จบ rustc ไม่ให้สร้าง

ลิสต์ที่ชี้ตัวเอง

enum List {
    Empty,
    More(i32, Box<List>),
}

fn sum(list: &List) -> i32 {
    match list {
        List::Empty => 0,
        List::More(n, rest) => n + sum(rest),
    }
}

fn main() {
    let scores = List::More(70, Box::new(List::More(80, Box::new(List::Empty))));
    println!("{}", sum(&scores));
}
150
  • Box::new ย้ายค่าไป heap แล้ว enum เก็บกล่องซึ่งขนาดรู้ได้
  • match แกะ More ได้ตัวเลขกับลิสต์ที่เหลือ
  • รวมได้ 150 จาก 70 กับ 80 ทาง Empty คือฐานของ recursion

ค่าธรรมดาอย่าง i32 ไม่ต้องใส่ Box กล่องมีประโยชน์เมื่อโครงสร้างต้องอ้างตัวเอง หรือเมื่ออยากย้ายก้อนใหญ่โดยไม่คัดลอกทั้งก้อนในที่นี้ดูแค่กรณีอ้างตัวเอง

สรุป

  • Box<T> วาง T บน heap
  • enum ที่อ้างตัวเองใส่ Box ที่ทางอ้างตัวเอง
  • ของเล็กที่ใช้ครั้งเดียวไม่ต้องกล่อง
