บทที่ 1 ตัวแปรกับชนิด

บทนี้ทำให้โปรแกรมจำค่าได้ ทั้งจำนวนเต็ม ทศนิยมยังไม่ใช้ ตัวอักษร และข้อความ แล้วเปลี่ยนค่าได้เมื่อตั้งใจให้เปลี่ยน

ในบทนี้

หน้าได้อะไร
1.1 let และ mutประกาศตัวแปร และรู้ว่าค่าเดิมแก้ไม่ได้จนกว่าจะใส่ mut
1.2 ชนิดตัวเลข bool charเลือกชนิดให้ตรงกับของที่เก็บ เช่น คะแนนกับจำนวนคน
1.3 String กับ &strแยกข้อความในเครื่องหมายคำพูดออกจากข้อความที่โปรแกรมเป็นเจ้าของ และอ่านหนึ่งบรรทัดจากคีย์บอร์ดได้
