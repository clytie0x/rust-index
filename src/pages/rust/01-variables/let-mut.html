1.1 let และ mut

โปรแกรมบทที่ 0 พิมพ์ข้อความเดิมทุกครั้ง โจทย์จริงให้ตัวเลขมาแล้วให้คำนวณต่อ เช่น คะแนนสองวิชา โปรแกรมจึงต้องมีที่จำค่า ที่จำนั้นเรียกว่า ตัวแปร (variable)

ประกาศด้วย let

ใน Rust การผูกชื่อกับค่าเรียกว่า binding เขียนด้วย let

fn main() {
    let score = 85; // (1)!
    println!("score = {score}"); // (2)!
}
  1. สร้างตัวแปรชื่อ score แล้วใส่ค่า 85 ชื่อใช้ภาษาอังกฤษ ตัวเล็ก เว้นคำด้วย _ ได้
  2. {score} ในข้อความคือช่องให้วางค่าของตัวแปรชื่อนั้น พิมพ์ชื่อในวงเล็บปีกกาได้เลย ไม่ต้องต่อท้ายแบบภาษาอื่น
score = 85

ตัวแปรสองตัวชนิดเดียวกันเขียนคนละบรรทัด อ่านง่ายกว่ายัดบรรทัดเดียว

fn main() {
    let math = 78;
    let science = 91;
    println!("math = {math}, science = {science}");
    println!("total = {}", math + science);
}

math = 78, science = 91
total = 169

{} ว่างๆ คือช่องค่าเหมือนกัน แต่ไม่ได้ผูกกับชื่อในวงเล็บ ค่าที่ตามหลังข้อความจะถูกเติมตามลำดับ ตรงนี้คือผลของ math + science

ค่าเดิมแก้ไม่ได้

ตัวแปรจาก let แก้ค่าไม่ได้ นี่เป็นค่าเริ่มต้นของภาษา ไม่ใช่ข้อจำกัดที่ลืมเปิด ลองโปรแกรมนี้ มันคอมไพล์ไม่ผ่าน

fn main() {
    let score = 85;
    score = 92;
    println!("{score}");
}

warning: value assigned to `score` is never read
 --> main.rs:2:9
  |
2 |     let score = 85;
  |         ^^^^^
  |
  = help: maybe it is overwritten before being read?
  = note: `#[warn(unused_assignments)]` on by default

error[E0384]: cannot assign twice to immutable variable `score`
 --> main.rs:3:5
  |
2 |     let score = 85;
  |         ----- first assignment to `score`
3 |     score = 92;
  |     ^^^^^^^^^^ cannot assign twice to immutable variable
  |
help: consider making this binding mutable
  |
2 |     let mut score = 85;
  |         +++

มีสองชั้น ชั้น warning บอกว่าค่า 85 ไม่ได้ถูกอ่าน เพราะโดนเขียนทับก่อน ชั้น error คือตัวที่ทำให้รันไม่ได้ มันบอกว่าตัวแปรนี้ immutable คือแก้ไม่ได้ และเสนอให้ใส่ mut

บรรทัด For more information about this error, try rustc --explain E0384 ถูกตัดออกจากกล่อง ถ้ารันเองจะเห็น รหัส E0384 ใช้เปิดคำอธิบายยาวได้

ใส่ mut เมื่อตั้งใจให้เปลี่ยน

mut ย่อจาก mutable แปลว่าเปลี่ยนค่าได้ ใส่เฉพาะตัวที่ต้องเปลี่ยน

fn main() {
    let mut score = 85;
    println!("first = {score}");
    score = 92;
    println!("second = {score}");
    score = score + 5;
    println!("with bonus = {score}");
}

first = 85
second = 92
with bonus = 97

บรรทัด score = score + 5 ไม่ได้แปลว่าเท่ากับในคณิตศาสตร์ เครื่องหมาย = แปลว่าเอาค่าทางขวาไปใส่ชื่อทางซ้าย คอมพิวเตอร์ทำสองจังหวะ คำนวณ 92 + 5 ได้ 97 แล้วใส่กลับลง score

อย่าใส่ mut ทุกตัว

ถ้าใส่ mut ทั้งที่ไม่ได้เปลี่ยนค่า rustc จะเตือน ตัวตรวจของเว็บนี้ถือว่าคำเตือนคือข้อผิดพลาด ใส่ mut เฉพาะตอนที่มีบรรทัดกำหนดค่าใหม่จริง

สรุป

  • let ชื่อ = ค่า; สร้างตัวแปรที่แก้ค่าไม่ได้
  • อยากแก้ค่า เขียน let mut
  • {ชื่อ} ใน println! คือที่วางค่าของตัวแปรนั้น
