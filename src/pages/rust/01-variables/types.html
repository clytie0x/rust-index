1.2 ชนิดตัวเลข bool char

ทุกค่าใน Rust มี ชนิด (type) ชนิดบอกว่ากล่องนี้เก็บของแบบไหน และใหญ่ได้แค่ไหน ถ้าไม่เขียนชนิดเอง ตัวเลขจำนวนเต็มที่ยังไม่มีบริบทจะเป็น i32

i32 กับ u64

ชนิดเก็บอะไรใช้เมื่อ
i32จำนวนเต็มมีเครื่องหมาย 32 บิต ตั้งแต่ -2147483648 ถึง 2147483647คะแนน จำนวนข้อ เลขที่ยังไม่ใหญ่มาก ค่าเริ่มต้นของเลขจำนวนเต็ม
u64จำนวนเต็มไม่ติดลบ 64 บิตจำนวนที่ใหญ่กว่าขอบของ i32 และไม่ติดลบ เช่น จำนวนคน
booltrue หรือ false เท่านั้นผ่านหรือไม่ผ่าน เปิดหรือปิด
charตัวอักษรหนึ่งตัว ในเครื่องหมายคำพูดเดี่ยวเกรดตัวเดียว สัญลักษณ์หนึ่งตัว

ตัว i มาจาก integer และมีเครื่องหมาย ตัว u มาจาก unsigned คือไม่มีเครื่องหมายลบ เลขข้างหลังคือจำนวนบิต

fn main() {
    let score: i32 = 85;
    let population: u64 = 3_000_000_000;
    let passed: bool = true;
    let grade: char = 'A';
    println!("{score}");
    println!("{population}");
    println!("{passed}");
    println!("{grade}");
}

  • : i32 คือการเขียนชนิดให้ชัด ใส่หลังชื่อตัวแปร
  • ขีดล่างใน 3_000_000_000 มีไว้ให้อ่านง่าย rustc ไม่คิดว่าเป็นคนละจำนวน
  • true ไม่มีเครื่องหมายคำพูด
  • 'A' ใช้คำพูดเดี่ยว เพราะเป็น char หนึ่งตัว

ลองทำให้พัง

เอาจำนวนที่ใหญ่เกินขอบของ i32 ไปใส่กล่อง i32

fn main() {
    let big: i32 = 3_000_000_000;
    println!("{big}");
}

error: literal out of range for `i32`
 --> main.rs:2:20
  |
2 |     let big: i32 = 3_000_000_000;
  |                    ^^^^^^^^^^^^^
  |
  = note: the literal `3_000_000_000` does not fit into the type `i32` whose range is `-2147483648..=2147483647`
  = help: consider using the type `u32` instead

rustc บอกช่วงที่ i32 รับได้ตรงๆ เลขสามพันล้านยังไม่เกิน u32 จึงเสนอชนิดนั้น ในตัวอย่างด้านบนใช้ u64 ซึ่งรับจำนวนนี้ได้เช่นกัน และเหลือที่ให้โตต่อ

อีกแบบที่เจอบ่อย คือใส่ข้อความคู่ให้กับ char

fn main() {
    let grade: char = "A";
    println!("{grade}");
}

error[E0308]: mismatched types
 --> main.rs:2:23
  |
2 |     let grade: char = "A";
  |                ----   ^^^ expected `char`, found `&str`
  |                |
  |                expected due to this
  |
help: if you meant to write a `char` literal, use single quotes
  |
2 |     let grade: char = 'A';
  |                       ~~~

เครื่องหมายคำพูดคู่คือข้อความ ชนิดของมันคือ &str ซึ่งเป็นคนละชนิดกับ char หน้าถัดไปจะแยกสองอย่างนี้ออกจากกัน

สรุป

  • จำนวนเต็มทั่วไปใช้ i32 จำนวนใหญ่ไม่ติดลบใช้ u64
  • bool มีแค่ true กับ false
  • ตัวอักษรหนึ่งตัวใช้ 'A' ไม่ใช่ "A"
