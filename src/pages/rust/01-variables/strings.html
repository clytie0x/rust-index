1.3 String กับ &str

ข้อความใน Rust มีสองชนิดที่ใช้ทุกวัน แยกให้ถูกตั้งแต่ต้น จะได้ไม่งงตอนยืมค่าในบทที่ 2

สองชนิด

  • &str คือมุมมองของข้อความที่มีอยู่แล้ว ข้อความในเครื่องหมายคำพูดคู่เป็นชนิดนี้
  • String คือข้อความที่โปรแกรมเป็นเจ้าของ ต่อท้ายและแก้ไขได้
fn main() {
    let nick = "Ann";
    let mut name = String::from("Ann");
    name.push_str(" Lee");
    println!("{nick}");
    println!("{name}");
    println!("len = {}", name.len());
}

Ann
Ann Lee
len = 7
  • "Ann" เป็น &str แก้ทีละตัวผ่านตัวแปรนี้ไม่ได้ และไม่ได้ใส่ mut
  • String::from สร้าง String จากข้อความนั้น :: คือการเรียกของที่อยู่ในชนิด String
  • push_str ต่อข้อความท้าย String จึงต้องเป็น let mut
  • len นับจำนวนไบต์ ไม่ใช่จำนวนตัวอักษรที่ตาเห็นเสมอไป

ภาษาไทยหนึ่งตัวอาจยาวกว่าหนึ่งไบต์

ตัวอักษรอังกฤษในตัวอย่างนี้หนึ่งตัวเท่ากับหนึ่งไบต์ จึงได้ 7 ภาษาไทยหนึ่งตัวอักษรมักยาว 3 ไบต์ ดูโปรแกรมถัดไป มันพิมพ์เลข ไม่ได้พิมพ์ภาษาไทยออกจอ

fn main() {
    let letter = "ก";
    println!("{}", letter.len());
}

3

ชุดเริ่มต้นนี้ให้โจทย์และผลลัพธ์เป็นภาษาอังกฤษหรือตัวเลขก่อน จะได้ไม่ไปชนเรื่องจำนวนไบต์

อ่านหนึ่งบรรทัด

แบบฝึกหัดต่อจากนี้รับข้อมูลจากคีย์บอร์ดหรือจากไฟล์ที่ส่งเข้าโปรแกรม สูตรด้านล่างยังใช้คำที่บทที่ 2 ค่อยอธิบาย เช่น &mut ตอนนี้จำทั้งก้อนได้ก่อน แล้วจะกลับมาแกะ

use std::io::BufRead;

fn main() {
    let mut line = String::new();
    std::io::stdin().lock().read_line(&mut line).unwrap();
    let name = line.trim();
    println!("Hello, {name}");
}

Ann

Hello, Ann
  • String::new คือข้อความว่างที่โตได้
  • read_line อ่านจนจบบรรทัด รวมตัวขึ้นบรรทัด แล้วต่อเข้า line
  • unwrap แปลว่า ถ้าอ่านไม่ได้ให้หยุดโปรแกรมทันที บทที่ 6 จะสอนวิธีที่ไม่ให้โปรแกรมดับแบบนี้
  • trim ตัดช่องว่างหัวท้ายและตัวขึ้นบรรทัดออก เหลือ Ann

ถ้าบรรทัดมีสองจำนวน คั่นด้วยช่องว่าง แยกแล้วแปลงเป็น i32 ได้แบบนี้

use std::io::BufRead;

fn main() {
    let mut line = String::new();
    std::io::stdin().lock().read_line(&mut line).unwrap();
    let mut parts = line.split_whitespace();
    let math: i32 = parts.next().unwrap().parse().unwrap();
    let science: i32 = parts.next().unwrap().parse().unwrap();
    println!("total = {}", math + science);
}

78 91

total = 169

split_whitespace ตัดบรรทัดเป็นคำตามช่องว่าง next หยิบคำถัดไป parse แปลงข้อความเป็นตัวเลข ชนิดปลายทางมาจาก : i32 ที่เราเขียนไว้

ยังไม่ต้องจำทุกคำ

แบบฝึกหัดบทนี้ใช้สองสูตรนี้ซ้ำ เน้นให้รันแล้วเทียบผลได้ก่อน ความหมายของ &mut อยู่หน้า 2.3

สรุป

  • เครื่องหมายคำพูดคู่คือ &str
  • String เป็นเจ้าของข้อความ และต่อท้ายได้เมื่อเป็น mut
  • len นับไบต์
  • อ่านหนึ่งบรรทัดด้วย read_line แล้ว trim ก่อนใช้
