10.2 trait

นักเรียนกับห้องสอบคนละ struct แต่ทั้งคู่ตอบคำถามคะแนนรวมได้ trait คือรายการเมธอดที่ชนิดต้องทำให้ ใคร impl ครบก็ส่งเข้าฟังก์ชันที่ขอสัญญานั้นได้

เขียนสัญญาแล้วทำให้

trait Summary {
    fn summary(&self) -> String;
}

struct Student {
    name: String,
    score: i32,
}

impl Summary for Student {
    fn summary(&self) -> String {
        format!("{} {}", self.name, self.score)
    }
}

fn show(item: &impl Summary) {
    println!("{}", item.summary());
}

fn main() {
    let student = Student {
        name: String::from("Ann"),
        score: 85,
    };
    show(&student);
    println!("{}", student.name);
}
Ann 85
Ann
  • trait บอกแค่ลายเซ็น ยังไม่มีตัวทำงาน
  • impl Summary for Student คือการทำให้ครบ
  • &impl Summary แปลว่ารับการยืมของชนิดใดก็ได้ที่ทำ Summary ฟังก์ชันจึงไม่ผูกกับ Student อย่างเดียว

ลองทำให้พัง

ส่ง struct ที่ไม่ได้ทำสัญญา rustc บอกว่า trait ยังไม่ถูกทำให้กับชนิดนั้น

trait HasScore {
    fn score(&self) -> i32;
}

fn show<T: HasScore>(item: T) {
    println!("{}", item.score());
}

struct Room {
    n: i32,
}

fn main() {
    show(Room { n: 4 });
}

สรุป

  • trait คือรายการเมธอดที่ต้องทำให้
  • impl Trait for Type ผูกสัญญากับชนิด
  • อาร์กิวเมนต์ impl Trait รับได้ทุกชนิดที่ทำสัญญานั้น
