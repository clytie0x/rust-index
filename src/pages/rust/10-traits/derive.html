10.3 Debug กับ derive

ตอนไล่ค่าใน struct ไม่อยากเขียน println ทีละฟิลด์ Debug คือ trait สำหรับพิมพ์ให้คนอ่านตอนพัฒนา derive ให้ rustc เขียน impl ให้จากฟิลด์ที่มี

พิมพ์ด้วยรูปแบบ Debug

#[derive(Debug)]
struct Score {
    math: i32,
    science: i32,
}

fn main() {
    let score = Score {
        math: 78,
        science: 91,
    };
    println!("math = {}", score.math);
    println!("science = {}", score.science);
    println!("{:?}", score);
}
math = 78
science = 91
Score { math: 78, science: 91 }

{:?} ขอรูปแบบ Debug วงเล็บปีกกาเปล่าขอรูปแบบแสดงผลปกติ ซึ่ง i32 มีอยู่แล้ว แต่ struct ที่เราเขียนเองไม่มี จนกว่าจะ derive หรือ impl เอง

อ่านฟิลด์ก่อนพิมพ์ทั้งก้อนในตัวอย่างนี้ เพราะตัวตรวจถือฟิลด์ที่ไม่มีใครอ่านเป็นคำเตือน Debug อย่างเดียวไม่นับว่าอ่านฟิลด์ ในโปรแกรมติวจริงมักได้ใช้ฟิลด์อยู่แล้ว

Clone เมื่อต้องสำเนา

#[derive(Clone)] ได้เมธอด clone ใช้เมื่อชนิดไม่ได้เป็น Copy แต่ต้องการสำเนา เช่น String ภายใน struct อย่า clone ทั้งก้อนทุกบรรทัด ทำเมื่อย้ายแล้วของเดิมยังต้องอยู่

สรุป

  • #[derive(Debug)] ให้พิมพ์ struct ทั้งก้อนได้
  • ใช้ {:?} ในข้อความของ println!
  • Clone เป็น derive อีกตัวที่ใช้บ่อยเมื่อต้องสำเนา
