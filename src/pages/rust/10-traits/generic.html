10.1 ฟังก์ชัน generic

ฟังก์ชันเลือกค่าที่มากกว่ากัน ถ้าเขียนรับ i32 อย่างเดียว ทศนิยมใช้ไม่ได้ generic คือการเว้นชนิดไว้เป็นชื่อ แล้วบอกสัญญาที่ชนิดนั้นต้องทำได้

สัญญา PartialOrd

T: PartialOrd แปลว่าชนิด T เทียบด้วย >= ได้ สัญญานี้เป็น trait หน้าถัดไปจะเขียน trait ของเราเอง ตอนนี้ใช้ของที่มีในภาษาก่อน

fn larger<T: PartialOrd>(a: T, b: T) -> T {
    if a >= b {
        a
    } else {
        b
    }
}

fn main() {
    println!("{}", larger(78, 91));
    println!("{}", larger(3.5, 2.5));
}
  1. T คือชื่อชนิดที่ยังไม่ระบุ ใส่ในวงเล็บมุมหลังชื่อฟังก์ชัน
  2. PartialOrd คือสัญญาว่าเทียบลำดับได้ จึงเขียน a >= b ได้
  3. เรียกกับ i32 ครั้งหนึ่งและทศนิยมครั้งหนึ่ง โดยไม่เขียนฟังก์ชันซ้ำ
91
3.5

สองอาร์กิวเมนต์ต้องเป็นชนิดเดียวกันในการเรียกหนึ่งครั้ง จะส่ง i32 กับทศนิยมปนกันในบรรทัดเดียวไม่ได้

สรุป

  • generic เว้นชนิดไว้เป็นชื่อเช่น T
  • สิ่งที่เขียนหลังชื่อ T คือ trait ที่ชนิดนั้นต้องทำ
  • แต่ละครั้งที่เรียก T เป็นชนิดเดียวทั้งฟังก์ชัน
