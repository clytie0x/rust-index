15.2 cargo test

ใส่ assert_eq! ใน main ได้ แต่ปนกับโปรแกรมจริง cargo test รันฟังก์ชันที่แปะ #[test] ให้ และไม่รัน main

ฟังก์ชันทดสอบ

บล็อกนี้ยังไม่ถูกตัวตรวจของเว็บคอมไพล์เป็นโปรแกรม เพราะตัวตรวจรัน main อย่างเดียว โครงสร้างนี้คือสิ่งที่ cargo test มองหา #[cfg(test)] ทำให้โมดูลทดสอบไม่อยู่ในโปรแกรมตอน cargo run

fn band(score: i32) -> &'static str {
    if score >= 80 {
        "A"
    } else if score >= 70 {
        "B"
    } else {
        "C"
    }
}

#[cfg(test)]
mod tests {
    use super::band;

    #[test]
    fn eighty_is_a() {
        assert_eq!(band(85), "A");
    }

    #[test]
    fn seventy_is_b() {
        assert_eq!(band(70), "B");
    }
}

ตัวอย่างที่ตัวตรวจรันได้คือการเรียกตรวจจาก main ผลเหมือนเทสผ่าน แล้วพิมพ์ ok

fn band(score: i32) -> &'static str {
    if score >= 80 {
        "A"
    } else if score >= 70 {
        "B"
    } else {
        "C"
    }
}

fn main() {
    assert_eq!(band(85), "A");
    assert_eq!(band(70), "B");
    println!("ok");
}
ok

คำสั่ง

cargo test
cargo test eighty

คำสั่งแรกวิ่งทุกเทส คำสั่งที่สองเลือกชื่อที่มีคำว่า eighty cargo fmt จัดบรรทัดให้เข้าแบบ rustfmt cargo clippy เตือนสไตล์เพิ่มจาก rustc ไม่บังคับในชุดนี้ แต่ใช้ได้เมื่อโปรเจกต์เริ่มยาว

สรุป

  • #[test] แปะฟังก์ชันที่ cargo test จะรัน
  • #[cfg(test)] กันไม่ให้เทสไปกับโปรแกรมจริง
  • cargo test ไม่ได้รัน main
