บทที่ 15 ทดสอบ cargo และเอกสาร

พอโปรแกรมยาว การกด cargo run แล้วมองจออย่างเดียวเริ่มพลาด บทนี้ล็อกผลที่ต้องได้ไว้ในโค้ด และบอกที่มาของฟังก์ชันด้วยคอมเมนต์เอกสาร

ในบทนี้

หน้าได้อะไร
15.1 assertให้โปรแกรมหยุดเองเมื่อผลไม่ตรงที่ล็อกไว้
15.2 cargo testแยกกรณีทดสอบออกจาก main แล้วรันทั้งชุดด้วยคำสั่งเดียว
15.3 คอมเมนต์เอกสารเขียนคำอธิบายเหนือฟังก์ชัน แล้วให้ cargo doc รวมเป็นหน้าเอกสาร
