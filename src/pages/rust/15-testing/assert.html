15.1 assert

พิมพ์แล้วมองจอจับความพลาดได้ตอนตัวอย่างสั้น พอมีหลายกรณี ให้เขียนผลที่ต้องได้ไว้ข้างฟังก์ชัน assert_eq! เทียบสองค่า ถ้าไม่เท่า โปรแกรมหยุดทันที

ล็อกเกรดสามกรณี

fn band(score: i32) -> &'static str {
    if score >= 80 {
        "A"
    } else if score >= 70 {
        "B"
    } else {
        "C"
    }
}

fn main() {
    assert_eq!(band(85), "A");
    assert_eq!(band(70), "B");
    assert_eq!(band(61), "C");
    println!("ok");
}
ok

ถึงบรรทัด ok แปลว่าทั้งสามกรณีตรง ถ้าแก้เกณฑ์แล้วลืมกรณี 70 โปรแกรมจะไม่พิมพ์ ok

ลองทำให้พัง

assert_eq! เทียบได้เมื่อสองข้างเป็นชนิดที่เทียบกันได้ เลขกับข้อความคนละชนิดจึงไม่ผ่านตั้งแต่คอมไพล์

fn main() {
    assert_eq!(1, "1");
}
error[E0277]: can't compare `{integer}` with `&str`
 --> main.rs:2:5
  |
2 |     assert_eq!(1, "1");
  |     ^^^^^^^^^^^^^^^^^^ no implementation for `{integer} == &str`
  |
  = help: the trait `PartialEq<&str>` is not implemented for `{integer}`

ตัดรายชื่อชนิดตัวเลขที่ทำ PartialEq ออกจากข้อความจริง เพราะยาวและไม่ได้ช่วยตอนติว ให้เทียบค่าชนิดเดียวกัน เช่น จำนวนกับจำนวน หรือข้อความกับข้อความ

สรุป

  • assert_eq! หยุดเมื่อสองค่าไม่เท่า
  • วางกรณีสำคัญไว้ก่อนงานจริง
  • สองข้างต้องเทียบชนิดกันได้
