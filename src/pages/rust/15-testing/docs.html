15.3 คอมเมนต์เอกสาร

คอมเมนต์ // คือโน้ตในไฟล์ คนที่เรียกฟังก์ชันมักไม่เลื่อนมาอ่าน คอมเมนต์เอกสารขึ้นต้นด้วยทับสามตัว วางทันทีเหนือฟังก์ชัน แล้วเครื่องมือดึงไปทำหน้าเอกสาร

ทับสามตัว

/// ผ่านเมื่อคะแนนตั้งแต่ 70
fn passed(score: i32) -> bool {
    score >= 70
}

fn main() {
    println!("{}", passed(85));
    println!("{}", passed(69));
}
true
false

ข้อความใน /// เป็นภาษาไทยได้ เพราะไม่ได้ถูกพิมพ์ออกจอ ผลของโปรแกรมยังเป็น true กับ false

เปิดหน้าเอกสาร

cargo doc --open

cargo สร้างหน้าจากคอมเมนต์เอกสารของ crate นั้น ใช้เมื่อโปรเจกต์มีหลายโมดูลจากบทที่ 9 และอยากให้คนในห้องเปิดอ่านโดยไม่ไล่ไฟล์

ชุดติวนี้จบที่เครื่องมือเหล่านี้ ยังมีเรื่อง unsafe แมโครขั้นสูง และ crate ภายนอกอีกมาก ไม่จำเป็นสำหรับทางติวจากศูนย์ถึงเขียนโปรแกรมเล็กที่ตรวจได้

สรุป

  • /// เหนือฟังก์ชันคือเอกสาร ไม่ใช่คอมเมนต์ธรรมดา
  • cargo doc รวมเอกสารของ crate
  • เทสกับเอกสารอยู่กับโค้ด จึงไม่หลุดจากพฤติกรรมจริง
