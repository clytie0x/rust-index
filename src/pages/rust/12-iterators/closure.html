12.1 closure

บางทีตรรกะใช้ครั้งเดียว เช่น บวกคะแนนพิเศษห้าแต้ม การตั้ง fn ใหม่ทั้งก้อนก็ได้ แต่ closure คือฟังก์ชันไม่มีชื่อ เขียนตรงอาร์กิวเมนต์หรือตัวแปรได้เลย

ขีดตั้งคู่กับอาร์กิวเมนต์

fn main() {
    let bonus = |score: i32| score + 5;
    println!("{}", bonus(80));
    let passed = |score: i32| score >= 70;
    println!("{}", passed(80));
    println!("{}", passed(60));
}
  1. หลัง = คือ closure |score: i32| คืออาร์กิวเมนต์ หลังขีดคือค่าที่คืน
  2. เรียกเหมือนฟังก์ชัน ด้วยวงเล็บ
  3. closure ที่คืน bool พิมพ์เป็น true หรือ false

ลองทำให้พัง

closure ที่ push ยืมลิสต์แบบแก้ได้ค้างไว้จนกว่าจะถูกเรียก ระหว่างนั้นอ่าน len ไม่ได้ เพราะอ่านกับการแก้ชนกัน แบบเดียวกับยืมสองแบบในบทที่ 2

fn main() {
    let mut scores = vec![70, 80];
    let mut add = || scores.push(90);
    println!("{}", scores.len());
    add();
}
error[E0502]: cannot borrow `scores` as immutable because it is also borrowed as mutable

  |                   |

เรียก add ให้จบก่อน แล้วค่อยอ่าน len หรืออย่าเก็บ closure ไว้ถ้ายังต้องใช้ลิสต์

สรุป

  • closure เขียน |อาร์กิวเมนต์| ค่าที่คืน
  • เรียกด้วยวงเล็บเหมือนฟังก์ชัน
  • ถ้ายืมแบบแก้ได้ การยืมอยู่จน closure ไม่ถูกใช้แล้ว
