12.2 map กับ filter

for บวกสะสมได้ แต่โจทย์เลือกเฉพาะคนที่ผ่านแล้วเก็บลิสต์ใหม่ อ่านเป็นประโยคได้ด้วย iterator filter เลือก map แปลง collect เก็บผล

เลือกคะแนนที่ผ่าน

fn main() {
    let scores = vec![60, 70, 85];
    let passed: Vec<i32> = scores.iter().copied().filter(|score| *score >= 70).collect();
    for score in &passed {
        println!("{score}");
    }
}
70
85
  • iter ยืมทีละช่อง copied คัดลอก i32 ออกมาเพราะเป็น Copy
  • filter ได้ตัวอ้างอิงของค่านั้น จึงเขียน *score ตอนเทียบ
  • collect ต้องบอกชนิด Vec<i32> เพราะมันเก็บลงได้หลายแบบ rustc ไม่เดาภาชนะให้

ลิสต์เดิม scores ยังอยู่ เพราะเริ่มจาก iter ไม่ได้ย้ายทั้งก้อน

สรุป

  • filter เก็บเฉพาะช่องที่ closure คืน true
  • collect ต้องระบุชนิดลิสต์ที่อยากได้
  • เริ่มจาก iter แล้วลิสต์เดิมยังใช้ต่อได้
