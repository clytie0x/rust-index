2.2 ยืมด้วย &

บ่อยครั้งฟังก์ชันแค่อยากอ่านข้อความ ไม่ได้อยากเป็นเจ้าของใหม่ การยืม (borrow) คือส่งสิทธิ์อ่านชั่วคราว โดยเจ้าของเดิมยังอยู่

เครื่องหมาย & ข้างหน้าค่าแปลว่ายืม ค่าที่ยืมมาของข้อความใช้ชนิด &str ได้ทั้งข้อความในเครื่องหมายคำพูดและ String ที่มีอยู่แล้ว

fn show(text: &str) { // (1)!
    println!("{text}");
}

fn main() {
    let name = String::from("Ann");
    show(&name); // (2)!
    show("Mali");
    println!("{name}"); // (3)!
}
  1. ฟังก์ชันรับ &str คือขอยืมข้อความมาอ่าน ไม่ได้ยึดเป็นของตัวเอง
  2. &name ยืม String ชื่อ name Rust ส่งต่อให้ฟังก์ชันที่รับ &str ได้
  3. หลังยืมจบ ชื่อ name ยังพิมพ์ได้ เพราะไม่ได้ถูกย้าย
Ann
Mali
Ann

เทียบกับหน้า 2.1 ถ้าเขียน show(name) โดยไม่มี & และฟังก์ชันรับ String ค่าจะถูกย้ายเข้าฟังก์ชัน พอบรรทัดสุดท้ายจะใช้ name ไม่ได้อีก หน้านี้เลือกยืมจึงพิมพ์ได้สามบรรทัด

ฟังก์ชันที่แค่อ่าน ให้รับ &str

ผู้เรียกจะส่งได้ทั้ง "Mali" และ &some_string ไม่ต้องสร้าง String ใหม่ทุกครั้ง

สรุป

  • & คือการยืม
  • &str คือข้อความที่ยืมมาอ่าน
  • ยืมแล้วเจ้าของเดิมยังใช้ต่อได้
