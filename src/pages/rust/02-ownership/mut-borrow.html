2.3 ยืมแบบแก้ได้

การยืมด้วย & อ่านได้อย่างเดียว ถ้าฟังก์ชันต้องแก้ค่าของเจ้าของ เช่น บวกคะแนน หรือต่อท้ายชื่อ ให้ยืมแบบแก้ได้ เขียนว่า &mut

บวกคะแนนผ่าน &mut

fn add_bonus(score: &mut i32) { // (1)!
    *score += 5; // (2)!
}

fn shout(name: &mut String) {
    name.push('!'); // (3)!
}

fn main() {
    let mut score = 80; // (4)!
    add_bonus(&mut score);
    println!("{score}");

    let mut name = String::from("Ann");
    shout(&mut name);
    println!("{name}");
}
  1. &mut i32 คือยืมจำนวนเต็มมาแก้ได้
  2. *score คือค่าที่อยู่ปลายทางของการยืม ต้องมี * เพราะ score ในฟังก์ชันนี้ไม่ใช่ตัวเลขเอง แต่เป็นตัวยืม
  3. เมธอดอย่าง push เรียกบนตัวยืมได้ตรงๆ ไม่ต้องใส่ *
  4. เจ้าของต้องเป็น let mut ถึงจะยืมแบบ &mut ได้

ลองทำให้พัง

แบบแรก ลืม mut ที่เจ้าของ แล้วเรียกเมธอดที่ต้องแก้ค่า

fn main() {
    let name = String::from("Ann");
    name.push('!');
    println!("{name}");
}

error[E0596]: cannot borrow `name` as mutable, as it is not declared as mutable
 --> main.rs:3:5
  |
3 |     name.push('!');
  |     ^^^^ cannot borrow as mutable
  |
help: consider changing this to be mutable
  |
2 |     let mut name = String::from("Ann");
  |         +++

แบบสอง ยืมแบบแก้ได้สองชื่อพร้อมกัน ทั้งที่ยังใช้ชื่อแรกไม่เสร็จ

fn main() {
    let mut score = 80;
    let a = &mut score;
    let b = &mut score;
    *a += 1;
    *b += 1;
    println!("{score}");
}

error[E0499]: cannot borrow `score` as mutable more than once at a time
 --> main.rs:4:13
  |
3 |     let a = &mut score;
  |             ---------- first mutable borrow occurs here
4 |     let b = &mut score;
  |             ^^^^^^^^^^ second mutable borrow occurs here
5 |     *a += 1;
  |     ------- first borrow later used here

กฎสั้นๆ คือ ช่วงที่ยืมแบบแก้ได้อยู่ จะมีผู้ยืมแบบแก้ได้แค่คนเดียว และจะไม่ให้ใครยืมอ่านคู่กันในช่วงนั้น ตัวอย่างนี้ a ยังถูกใช้ที่บรรทัด 5 จึงยังยืมไม่จบ พอสร้าง b คาบเกี่ยวกัน rustc จึงไม่ให้ผ่าน

แก้ด้วยการใช้งาน a ให้จบก่อน แล้วค่อยสร้าง b หรือบวกบน score ทีละครั้งโดยไม่ถือการยืมสองอันพร้อมกัน

สรุป

  • &mut คือยืมมาแก้
  • เจ้าของต้องเป็น mut และจุดที่ส่งต่อเขียน &mut ชื่อ
  • จำนวนเต็มที่ถูกยืม แก้ด้วย *ชื่อ
  • ยืมแบบแก้ได้พร้อมกันได้ทีละที่
