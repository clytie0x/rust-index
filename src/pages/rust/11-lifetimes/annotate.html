11.2 เขียน lifetime ให้ฟังก์ชัน

ป้าย lifetime ผูกการยืมขาเข้ากับขาออก ผลที่คืนใช้ได้ไม่นานกว่าค่าที่มันชี้ไป

ป้ายเดียวกันทั้งสามที่

fn longer<'a>(a: &'a str, b: &'a str) -> &'a str {
    if a.len() >= b.len() {
        a
    } else {
        b
    }
}

fn main() {
    let ann = String::from("Ann");
    let mali = String::from("Mali");
    let text = longer(&ann, &mali);
    println!("{text}");
}
  1. 'a เป็นชื่อป้าย ใส่หลังชื่อฟังก์ชันเหมือนชื่อชนิดของ generic
  2. ทั้ง a b และค่าที่คืนใช้ป้ายเดียวกัน ผลจึงอยู่ได้ตราบใดที่ทั้งสองตัวยังอยู่
  3. ข้อความในเครื่องหมายคำพูดก็ส่งได้ เพราะมีชีวิตยาวพอ ตัวอย่างนี้ใช้ String เพื่อให้เห็นว่าผลยืมของใน main
Mali

บางลายเซ็น rustc เติมให้

ถ้ามีตัวยืมเข้าตัวเดียวและคืนตัวยืมออกหนึ่งตัว rustc เดาได้ว่าขาออกมาจากขาเข้า ไม่ต้องเขียนป้ายเอง กฎนี้เรียกว่า lifetime elision

fn first_word(text: &str) -> &str {
    text.split_whitespace().next().unwrap_or("")
}

fn main() {
    println!("{}", first_word("Ann Lee"));
}
Ann

ฟังก์ชัน longer เดาไม่ได้เพราะมีสองทางเข้า ฟังก์ชัน first_word มีทางเข้าทางเดียว จึงละป้ายได้ ถ้าไม่แน่ให้เขียนป้ายเอง โปรแกรมยังหมายถึงอย่างเดียวกัน

สรุป

  • 'a บอกว่าการยืมขาออกมาจากการยืมขาเข้าชุดนั้น
  • ป้ายไม่ได้เปลี่ยนระยะจริงของค่า มันแค่ให้ลายเซ็นพูดความจริง
  • ตัวยืมเข้าตัวเดียวแล้วคืนตัวยืม มักไม่ต้องเขียนป้าย
