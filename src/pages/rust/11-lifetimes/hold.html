11.3 struct ที่เก็บการยืม

struct ในบทที่ 5 ถือ String จึงเป็นเจ้าของชื่อ บางก้อนแค่แปะป้ายบนข้อความที่มีเจ้าของอยู่แล้ว เช่น ชื่อที่อยู่ในบัฟเฟอร์ที่อ่านมาทั้งก้อน struct แบบนั้นต้องบอกว่าฟิลด์ยืมของใคร

ฟิลด์ที่เป็นการยืม

struct Label<'a> {
    text: &'a str,
}

fn main() {
    let name = String::from("Ann");
    let label = Label { text: &name };
    println!("{}", label.text);
    println!("{}", name);
}

ป้าย 'a บน struct ผูกกับฟิลด์ text label ใช้ได้ไม่นานกว่า name หลังสร้างยังพิมพ์ name ได้เพราะเป็นการยืม ไม่ใช่การย้าย

อย่าคืนการยืมของตัวแปรในฟังก์ชัน

ถ้าสร้าง String ในฟังก์ชันแล้วคืน Label ที่ชี้ไปหาตัวนั้น พอฟังก์ชันจบตัวแปรถูกทิ้ง ป้ายจะไม่มีของให้ชี้ rustc ไม่ให้ผ่าน ทางที่ใช้คือคืน String ให้ผู้เรียกเป็นเจ้าของ แล้วค่อยสร้าง Label ข้างนอก

สรุป

  • struct ที่เก็บ &str ต้องมี lifetime
  • ก้อนนั้นอยู่ได้ไม่นานกว่าค่าที่ฟิลด์ยืม
  • ถ้าต้องให้ก้อนอยู่ต่อหลังจากเจ้าของเดิมตาย ให้ถือ String แทน
