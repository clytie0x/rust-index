8.3 เงื่อนไขใน match

บางแขนอยากรับค่าแล้วยังถามเงื่อนไขต่อ เช่น รับตัวเลขมาได้แต่จะให้เกรด A เฉพาะที่ตั้งแต่ 80 เงื่อนไขท้ายรูปแบบเรียกว่า guard

guard

fn label(score: i32) -> &'static str {
    match score {
        n if n >= 80 => "A",
        n if n >= 70 => "B",
        _ => "C",
    }
}

fn main() {
    println!("{}", label(85));
    println!("{}", label(75));
    println!("{}", label(61));
}

B
C

แขนบนถูกตรวจก่อน ถ้า guard ไม่จริง จะไปแขนถัดไป ทั้งที่รูปแบบ n จับตัวเลขได้ทุกค่า ลำดับแขนจึงมีความหมาย

รวมหลายค่าด้วย |

fn is_edge(score: i32) -> bool {
    match score {
        0 | 100 => true,
        _ => false,
    }
}

fn main() {
    println!("{}", is_edge(0));
    println!("{}", is_edge(80));
    println!("{}", is_edge(100));
}
true
false
true

0 | 100 คือค่าใดค่าหนึ่งในสองจำนวนนี้ ใช้เมื่อหลายค่าทำอย่างเดียวกัน ไม่ต้องเขียนแขนซ้ำ

สรุป

  • เขียน รูปแบบ if เงื่อนไข เพื่อกรองแขนเพิ่ม
  • แขนบนก่อน ถ้า guard ไม่จริงจึงหล่นไปแขนถัดไป
  • | รวมหลายรูปแบบในแขนเดียว
