8.2 if let และ while let

match เหมาะเมื่อทุกทางมีความหมาย ถ้าสนใจแค่ Some แล้วทาง None คือข้ามไป if let สั้นกว่า

if let

fn main() {
    let found = Some(85);
    if let Some(n) = found {
        println!("{n}");
    }

    let missing: Option<i32> = None;
    if let Some(n) = missing {
        println!("{n}");
    } else {
        println!("missing");
    }
}
85
missing

รูปแบบอยู่หน้า = ค่าอยู่หลัง ถ้าเข้ากันได้ ชื่อในรูปแบบใช้ได้ในบล็อก ถ้าไม่เข้าและมี else จะไปทางนั้น

while let

Vec::pop ดึงตัวท้ายออกแล้วคืน Option วนจนกว่าจะว่างได้ด้วย while let ตัวเลขเลยออกทีหลังก่อน

fn main() {
    let mut scores = vec![70, 80, 90];
    while let Some(n) = scores.pop() {
        println!("{n}");
    }
    println!("left = {}", scores.len());
}
90
80
70
left = 0

if let ไม่ได้ตรวจว่าคิดครบทุกทาง

ถ้า enum มีสามทางแล้วเขียน if let แค่ทางเดียว อีกสองทางหายเงียบๆ ใช้เมื่อตั้งใจข้าม ถ้าทุกทางต้องมีผล ให้กลับไป match

สรุป

  • if let รูปแบบ = ค่า ทำงานเมื่อจับคู่ได้
  • while let วนตราบเท่าที่ยังจับคู่ได้
  • ทางที่ไม่ได้เขียนจะถูกข้าม จึงไม่แทน match ที่ต้องครบ
