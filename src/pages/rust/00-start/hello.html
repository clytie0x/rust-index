0.2 โปรแกรมแรก

โปรแกรมแรกคือสั่งให้พิมพ์ข้อความออกจอ ถ้าหน้านี้รันผ่าน แปลว่าเครื่องพร้อมเริ่มเรียนแล้ว

ขั้นที่ 1 สร้างโปรเจกต์

เปิดเทอร์มินัล ไปที่โฟลเดอร์ที่ใช้เก็บงาน แล้วรัน

cargo new hello
cd hello

cargo new สร้างโฟลเดอร์ hello ให้ พร้อมไฟล์ที่ต้องมี ไฟล์ที่เราจะแก้คือ src/main.rs

ขั้นที่ 2 ดูโค้ดที่ cargo เขียนให้

เปิด src/main.rs จะเห็นโปรแกรมนี้ พิมพ์ตามได้ถ้าอยากเริ่มจากไฟล์ว่าง แต่ของที่ cargo ให้มาตรงกับด้านล่างอยู่แล้ว

fn main() { // (1)!
    println!("Hello, world!"); // (2)!
}
  1. fn ย่อจาก function คือฟังก์ชัน main คือจุดเริ่มของโปรแกรม รันเมื่อไรจะเริ่มที่นี่ ปีกกาเปิดวางบรรทัดเดียวกับชื่อฟังก์ชัน
  2. println! พิมพ์ข้อความแล้วขึ้นบรรทัดใหม่ เครื่องหมาย ! บอกว่านี่คือมาโคร (macro) ไม่ใช่ฟังก์ชันธรรมดา คำสั่งจบด้วย ;

กดวงกลมตัวเลขในโค้ดเพื่อดูคำอธิบายทีละจุด ปีกกา { } ครอบคำสั่งที่อยู่ใน main เปิดปีกกาไว้บรรทัดเดียวกับ fn main() ตามแบบที่ cargo จัดให้

ขั้นที่ 3 รัน

cargo run

ครั้งแรกรอสักครู่ cargo จะคอมไพล์ก่อน แล้วรันให้ บรรทัดที่โปรแกรมพิมพ์คือบรรทัดนี้

Hello, world!

บนเทอร์มินัลจะมีบรรทัด Compiling กับ Finished เพิ่มมา cargo พิมพ์เองทางช่องคนละช่องกับผลของโปรแกรม กล่องด้านบนแสดงเฉพาะสิ่งที่โปรแกรมพิมพ์

ยังไม่มีสนามทดลองในเบราว์เซอร์

ชุดเริ่มต้นนี้รันบนเครื่องตัวเองด้วย cargo run เท่านั้น

ลองเปลี่ยนดู

  1. เปลี่ยนข้อความเป็นชื่อตัวเองแบบตัวอังกฤษ แล้วรันใหม่
  2. เพิ่ม println! อีกบรรทัด ให้พิมพ์สองบรรทัด

ตัวอย่างที่สองบรรทัด รันแล้วได้แบบนี้

fn main() {
    println!("Hello, Ann");
    println!("Rust");
}

Hello, Ann
Rust

สรุป

  • cargo new ชื่อโปรเจกต์ สร้างโฟลเดอร์ให้
  • แก้ที่ src/main.rs
  • cargo run คือคอมไพล์แล้วรัน
  • ทุกโปรแกรมในชุดนี้มี fn main หนึ่งตัว

กลับไปเช็กรายการ ผ่านบทนี้เมื่อ ได้สองข้อแรกแล้ว ค่อยไปอ่าน error ที่หน้าถัดไป
