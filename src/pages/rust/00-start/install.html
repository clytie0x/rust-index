0.1 ติดตั้ง rustup

Rust ติดตั้งผ่านโปรแกรมชื่อ rustup มันจัดการตัวแปลภาษา rustc (compiler) กับเครื่องมือสร้างโปรเจกต์ cargo ให้ ใช้ชุดนี้ชุดเดียวทั้งตอนเรียนและตอนตรวจโค้ดในเว็บ

ขั้นที่ 1 ติดตั้ง

  1. เปิด https://rustup.rs/
  2. ทำตามคำสั่งของระบบตัวเอง บน Windows คือดาวน์โหลด rustup-init.exe แล้วรัน บน macOS กับ Linux คือวางคำสั่ง curl ที่เว็บให้ไว้ลงเทอร์มินัล
  3. พอตัวติดตั้งถาม ให้เลือกค่าเริ่มต้น (default) กด Enter ตามที่มันบอก

เปิดเทอร์มินัลใหม่หลังติดตั้ง

หน้าต่างเทอร์มินัลที่เปิดค้างไว้ก่อนติดตั้งจะยังไม่รู้จัก cargo ปิดแล้วเปิดใหม่ก่อนลองคำสั่งขั้นถัดไป

ขั้นที่ 2 ตรวจว่าใช้ได้

พิมพ์สองคำสั่งนี้ คนละครั้ง

rustc --version
cargo --version

ต้องเห็นเลขรุ่นขึ้นมา ทั้งคู่ เลขกับวันที่ไม่ต้องตรงกับตัวอย่างนี้ ขอแค่มีบรรทัดตอบกลับ ไม่ใช่ข้อความว่าไม่พบคำสั่ง

rustc 1.83.0 (90b35a623 2024-11-26)
cargo 1.83.0 (5ffbef321 2024-10-29)

เลขรุ่นคนละเครื่องไม่เป็นไร

เอกสารนี้ตรวจด้วย edition 2021 ซึ่ง rustup รุ่นปัจจุบันรองรับอยู่แล้ว ยังไม่ต้องสนใจคำว่า nightly หรือ beta

ใช้โปรแกรมอะไรพิมพ์โค้ด

ใช้โปรแกรมแก้ไขข้อความตัวไหนก็ได้ โน้ตแพด VS Code หรือตัวที่ถนัด ชุดนี้ไม่ได้ผูกกับโปรแกรมตัวใดตัวหนึ่ง สิ่งที่ต้องมีคือเทอร์มินัลที่รัน cargo ได้

สรุป

  • rustup เป็นตัวติดตั้ง
  • rustc เป็นคอมไพเลอร์ แปลโค้ด Rust เป็นโปรแกรม
  • cargo เป็นตัวสร้างโปรเจกต์และสั่งคอมไพล์ให้ บทหน้าจะใช้คำสั่งนี้เป็นหลัก
